프로그램 내 자동 업데이트 1.0.0

최초 1회
프로그램을 종료하고 Patch_AutoUpdate.ps1을 적용합니다.
기존 maple_loot_counter.py를 선택하고 완료되면 기존 run.bat으로 실행하세요.
기록·설정·API 키·OCR 모델은 이 패키지에 포함하지 않습니다.

이후 업데이트
- 프로그램 시작 후 새 버전이 있는지 백그라운드로 확인합니다.
- 새 버전이 있으면 상단 버튼에 버전이 표시됩니다. 게임 중 팝업은 띄우지 않습니다.
- '업데이트 확인' → 새 버전 설명 확인 → 적용을 누르면 다운로드합니다.
- 다운로드와 SHA-256 검증을 마친 다음 측정을 정지하고 기록을 저장합니다.
- 프로그램이 완전히 종료된 뒤 파일을 백업하고 교체합니다.
- 적용 후 프로그램을 다시 실행합니다.
- 설정, 사냥 기록, API 키는 패치하지 않습니다.
- 백업은 기존 프로그램 폴더/update_backups에 남습니다.
- 파일 교체 중 오류가 나면 교체한 파일을 백업으로 되돌립니다.
- update_result.txt에서 마지막 적용 결과와 오류를 확인할 수 있습니다.
- 네트워크 오류/검증 실패일 때는 설치 파일을 변경하지 않습니다.
- 기존 EXE에는 적용되지 않습니다. run.bat 버전에 적용한 후 EXE를 재빌드해야 합니다.
- 전원 강제 종료 또는 새 버전 자체의 실행 오류까지 자동 복구하는 기능은 아닙니다.
- 파이썬 라이브러리나 OCR 모델을 자동 설치/교체하는 기능은 아닙니다.

배포 위치
https://github.com/taehyeon189-ui/-
새 버전 확인: main/update.json
패키지: main/versions/버전.json
현재 배포: 1.0.0. 새 패치가 이 저장소에 게시되어야 프로그램에서 찾을 수 있습니다.
프로그램이 자체적으로 코드를 수정하거나 새 패치를 만드는 것은 아닙니다.

개발/배포 순서
1. 수정한 배포 코드를 검증하고 app_updater.py의 VERSION을 올립니다.
2. 개인 설정을 제외한 배포 파일만 format=1, version, files(base64) JSON으로 묶습니다.
3. 패키지의 SHA-256을 계산해 update.json의 version/package/sha256/notes를 작성합니다.
4. versions/새버전.json과 update.json을 같은 커밋으로 게시합니다.
5. 원격에서 파일을 받아 해시와 버전을 확인합니다.
기존 versions 파일은 덮어쓰지 않습니다. 이 저장소 이름/소유자를 바꾸면 업데이트 주소도 수정해야 합니다.

검증
패키지 변조, 잘못된 경로, 개인 파일 포함, 파이썬 문법 오류, 버전 오류,
정상 적용·백업·설정 유지, 파일 교체 오류 시 복구에 대한 자동 검사를 수행했습니다.
실제 Windows에서 종료 후 재실행되는 과정은 이 환경에서 직접 실행하지 못했습니다.
